# Fazenda Garden Itajaí

Site estático do empreendimento Fazenda Garden, com atendimento Āgama Imóveis.

Os arquivos publicados ficam em `fazenda-garden-site/`. O arquivo `netlify.toml`
configura essa pasta como diretório de publicação na Netlify. Não é necessário
executar um comando de build.

Para atualizar o site, edite os arquivos dessa pasta. O arquivo
`fazenda-garden-site.zip` é o pacote original e não é usado na publicação.
